# Codex Sidebar Keeper

一个独立的 Codex 个人插件，用来把 Codex Desktop 的右侧工作面板稳稳留在你需要的位置。切换对话时，它可以保持右侧栏打开，也可以按你的习惯保留侧边聊天、浏览器或终端。

![顶部栏入口](assets/readme/topbar-entry.svg)

## 它解决什么

在 Codex 里频繁切换对话时，右侧工作区容易被收起、切错工具，或者浏览器标签回到不想要的页面。Sidebar Keeper 做的事情很简单：记住你的右侧工作习惯，并尽量不打扰当前主对话。

| 场景 | Sidebar Keeper 的处理 |
| --- | --- |
| 只想保持右侧栏展开 | 选择 `只打开`，只展开侧边栏，不强行切工具 |
| 常用侧边聊天/浏览器/终端 | 选择目标后，切换对话时自动回到对应右侧工具 |
| 右侧标签太多 | 开启 `一次只保留一个右侧标签`，只保留当前目标 |
| 浏览器第一次打开 | 默认停在 `此聊天网址`，不会主动跳转 |
| 浏览器已经选过网页 | 下次优先打开你上次为这个对话选择的网页 |
| 新建对话 | 只保持右侧栏状态，不把主界面拉回旧对话 |

## 界面预览

### 轻量顶部入口

顶部栏入口贴近 Codex 原生工具栏样式，只保留一个清晰的状态点和入口文字。

![顶部栏入口示意图](assets/readme/topbar-entry.svg)

### 深色设置面板

设置面板保持紧凑、深色、可拖动。常用开关和目标按钮放在第一屏，状态提示放在底部。

![设置面板示意图](assets/readme/settings-panel.svg)

### 浏览器网址记忆

浏览器网址下拉框会优先显示网页标题；拿不到标题时才显示网址。缓存会过滤对话正文、终端提示、错误页标题等误识别内容。

![浏览器网址选择流程](assets/readme/browser-url-flow.svg)

## 功能

- 切换对话后自动保持 Codex 右侧工作面板打开。
- 支持 `只打开`、`侧边聊天`、`浏览器`、`终端` 四种打开后状态。
- 开启 `切换对话时保持打开` 后默认回到 `只打开`，避免立刻自动切换到工具。
- 关闭 `切换对话时保持打开` 时，侧边聊天、浏览器和终端只显示提示，不会强行打开。
- `一次只保留一个右侧标签` 会关闭多余的右侧标签，并尽量保持当前主对话不被拉走。
- 浏览器模式首次默认 `此聊天网址`，用户选择具体网页后会按对话记住。
- 支持浅色/深色面板、面板置顶、拖动面板位置和状态提示。

## 使用

打开 Codex Desktop 顶部栏里的 `Sidebar Keeper` 控件。

1. 打开 `切换对话时保持打开`，让插件在切换对话后维持右侧栏。
2. 在 `打开后显示` 中选择 `只打开`、`侧边聊天`、`浏览器` 或 `终端`。
3. 如果选择 `浏览器`，可以在 `浏览器网址` 下拉框里选择当前对话要记住的网页。
4. 想让右侧更清爽时，打开 `一次只保留一个右侧标签`。

脚本只在 Codex 主应用界面运行。右侧栏里打开的网页不会触发这个自动化逻辑。

## 安装

插件清单位于：

```text
.codex-plugin/plugin.json
```

插件会暴露 `codex-sidebar-keeper` skill，并附带用于本地验证和备用热键的脚本。

## 开发与检查

校验插件清单：

```powershell
python <path-to-plugin-creator>\scripts\validate_plugin.py .
```

检查用户脚本语法：

```powershell
node --check .\market\scripts\codex-sidebar-keeper.js
```

通过 CDP 查看当前 Codex 窗口里的脚本状态：

```powershell
.\scripts\Invoke-CodexCdp.ps1 -Port <debug-port> -Expression "window.__codexSidebarKeeper.getState()"
```
